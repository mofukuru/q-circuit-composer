# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback gracefully, and do not harass, insult or demean anyone. This applies in issues, pull requests, discussions and any other project space.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer [@mofukuru](https://github.com/mofukuru) privately. Reports will be reviewed promptly and handled confidentially.
